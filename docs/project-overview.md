**IoT Homelab & Smart Home Infrastructure**

This project focuses on designing, building, and configuring a local server for IoT, home automation, and network management. The goal is to create a secure and scalable environment for running various services using virtualization and containers.

**Q1 Network & Architecture (Phase 1)**
The main goal for Q1 was to build a stable network and prepare the virtualization hardware. I replaced the originally planned Raspberry Pi 5 with a more powerful HP Mini PC. It offers much better performance for the same price and fits perfectly into the project.

**Current Status (End of Q1):**
* Separated and managed home network (Omada Router + Switch).
* Expanded Wi-Fi coverage by setting up an old router as an Access Point (AP).
* Proxmox VE installed on the Mini PC, ready for virtual machines and LXC containers.
